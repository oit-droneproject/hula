# Hula-jp

Hula（フラ）は、プログラミング学習用のドローンです。Pythonでプログラミングで飛行を制御できるほか、専用アプリ「Hula APP」自由に飛ばすこともできます。
機体には、ビジュアル・ポジショニング（位置測定）、ジンバル、映像伝送、障害物回避、飛行制御の各システムを搭載しています。
これにより、1080PのHD映像伝送、写真・動画の撮影、AIによる画像認識、障害物回避、ライン追従（ラインパトロール）飛行、各種の飛行アクロバットなど、多彩な機能を実現します。
